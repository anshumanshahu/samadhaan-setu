# Samadhaan Setu

Samadhaan Setu is an AI-powered civic issue reporting Progressive Web App (PWA) that helps citizens report common civic problems such as potholes, garbage overflow, water leakage, and manholes.

## Features

- Precise location capture with latitude and longitude
- Image-based civic issue classification
- Automatic department-wise issue routing
- Separate admin panels for different civic departments
- Complaint status tracking
- Delayed complaint escalation
- City-wise issue visibility
- Resolution transparency with before/after images
- Transparency leaderboard

## AI Model

Samadhaan Setu uses **MobileNetV2 with Transfer Learning** for image classification, served through a dedicated Python microservice.

- Dataset: ~4,000 collected images
- Classes:
  - Pothole
  - Garbage Overflow
  - Water Leakage
  - Manhole
  - Unknown
- Training: Google Colab (GPU)
- Framework: TensorFlow / Keras
- Model Serving: FastAPI (Python microservice)

### Model Flow

Citizen Image
↓
React Frontend (image upload)
↓
Node.js/Express Backend
↓
FastAPI ML Microservice (MobileNetV2)
↓
Civic Issue Category + Confidence Score
↓
Relevant Department

## Architecture

The system follows a microservice-based architecture where the Node.js backend handles core application logic (users, complaints, departments, admin), while a separate FastAPI service exclusively handles AI model inference. The Node backend communicates with the FastAPI service internally via REST API calls.

```
React (Frontend) → Node.js/Express (Main Backend) → FastAPI (ML Service) → MobileNetV2 Model
```

## Workflow

1. Citizen opens the PWA.
2. The application fetches the user's precise location.
3. Latitude and longitude are shown to the citizen.
4. Citizen uploads an image of the civic issue.
5. Node backend forwards the image to the FastAPI ML service.
6. MobileNetV2 (via FastAPI) classifies the image and returns the category with a confidence score.
7. The issue is routed to the appropriate department.
8. Admin assigns the issue to a field worker.
9. The issue status is updated.
10. After resolution, evidence can be uploaded.
11. Citizens can view the progress for transparency.

## Escalation

If an issue remains inactive for a defined period, such as 3 days, the system can notify a higher-level administrator for escalation.
